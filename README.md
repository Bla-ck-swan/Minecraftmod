这是一些目前较高版本java版我的世界模组。我目前对java并不精通，其中也可能还有很多我不知道问题或bug。如果有人可以找出问题或提出意见，我将十分感激。以下是对各个模组的介绍：

一：ElytraSlot

核心功能：

在副手位置上方加入一个自定义槽，只能存放鞘翅，并禁用胸甲槽可以存放鞘翅的功能，达到可以同时在身上穿戴胸甲与鞘翅的目的。并且鞘翅飞行判定，飞行粒子/音效，鞘翅模型渲染，耐久消耗，附魔效果，物品/装备交互，数据同步，持久化（存档）等均走原版逻辑，兼容性较强。

已知问题：

1.游戏内（特别是多人模式）图像渲染有时会出问题

2.在（多人游戏，服务器）游戏规则内keepInventory=true时死亡后不复活直接退出并且服务器端重启会丢失鞘翅槽的物品

这些bug都不影响游戏体验甚至很难触发，目前修复成本大于收益，暂不修复

使用方式：

单人存档直接拖入mods文件夹，多人（服务器）要正常使用需要双端（服务器，客户端）下载，双端共用一个jar文件即可

jar位置：

ElytraSlot\\build\\libs\\elytraslot-1.0.0.jar

适用版本：

26.2-fabric
